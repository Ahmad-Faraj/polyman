polyman on GitLab · Path B · Assisted

polyman (polyman-cli on npm, MIT) is a command-line tool that checks that every solution of a contest problem gets the verdict it should. A wrong verdict means a broken problem in a live contest round.

On GitLab, Duo agents maintain it. Every agent step waits for a go-ahead from a person who did not ask for the work, and CI refuses an agent push without one.

An agent never raises its own level; only a person does.
