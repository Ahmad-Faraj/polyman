What the check does

polyman's own ten steps, in three parts. These are the steps you watch tick off in the card.

  1. Make the tests, then prove them

    It builds the generators, generates every test, builds the validator, tests it, and checks that every generated test is valid.

  2. Prove the checker

    The problem's own answer checker is built and run on its own tests, because it decides every answer that follows.

  3. Judge every solution

    Each solution is compiled and run on the tests with the problem's time and memory limits, in a sandbox with no internet, then compared with its label.

Built on polyman, the open-source CLI for problem setters.
