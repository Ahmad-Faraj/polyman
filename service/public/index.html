What gets checked

It runs

Generators, validator and its tests, checker and its tests, every solution on every test, with the time and memory limits from Config.json.

It compares

Each solution's verdicts against its tag: MA and OK must pass everything, WA must fail somewhere, TL must time out, and so on.

It reviews

Statement sections, at least ten tests, checker and validator present, correct solutions in C++ and Java plus a wrong one, tags, tutorial.

Your upload is deleted when the check ends. Your code runs as its own user, with no route to the internet.

Built on polyman, the CLI for Codeforces problem setters.
