What the check does

The same checks a contest coordinator runs by hand, done in one pass.

  1. You send a problem

    A contest problem is a statement, its tests, a correct solution, and solutions that are meant to fail, each labelled with how it should fail.

  2. It is judged for real

    Real compilers run every solution on every test with the problem's own time and memory limits, in an isolated sandbox with no internet access.

  3. You get a plain answer

    Which solution doesn't behave as labelled, on which tests, what to change, and whether the problem meets common contest guidelines.

Your upload is deleted when the check ends. Nothing is stored.

Built and shipped on GitLab

AI agents write changes to this service on GitLab, and they start only after a person says go ahead. CI rebuilds the record of every go-ahead from GitLab's own data, so you can check it yourself.

  • Go-ahead ledgerEvery push an agent made, judged against who said go ahead. Hash-chained, so a record can't be changed later.
  • PipelinesThe builds, tests and deploys behind this page.
  • Agent carbonWhat the review agents emit per merge request, as Software Carbon Intensity.
  • SourceThe service, the agents' setup and this page.
