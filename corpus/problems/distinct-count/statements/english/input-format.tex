The first line contains the number of test cases $T$ ($1 \le T \le 10^4$).

Each test case takes two lines. The first contains $n$ ($1 \le n \le 2 \cdot 10^5$), the second contains $n$ integers $a_1, a_2, \ldots, a_n$ ($1 \le a_i \le 10^9$).

The sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.
